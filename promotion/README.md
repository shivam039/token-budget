# Distribution / promotion pass

This directory is the output of a distribution-only pass for
`@shivam.dixit/token-budget` — no product changes, no API changes, no
new packages. Goal: get real developers building LLM agents to discover
the project, not to maximize the number of places it's listed.

## Files

- **`descriptions.md`** — canonical 1-sentence / 50–80 word / 150–200
  word descriptions and "why this exists," for reuse across every
  channel instead of rewriting copy each time.
- **`keywords.md`** — 15 natural developer search phrases.
- **`npm-directories-research.md`** — npm/JS ecosystem discovery
  (npm itself, libraries.io, npms.io, GitHub Topics) plus two
  awesome-lists found during that research.
- **`ai-directories-research.md`** — AlternativeTo and 9 AI/product
  directories, each checked for real current pricing/fit rather than
  assumed.
- **`awesome-list-candidates.md`** — full GitHub awesome-list research:
  2 strong candidates, 1 moderate, 8 verified rejects with reasons.
- **`awesome-list-submissions.md`** — exact, copy-paste-ready PR content
  for the 2 strong awesome-list candidates (not opened as real PRs —
  see the note in that file for why).
- **`POTENTIAL_USERS.md`** — 8 real, active GitHub projects doing naive
  context trimming today, found via code search, with the actual code
  and why token-budget would help. Discovery only, no outreach made.
- **`community-posts.md`** — drafts for Hacker News, 4 subreddits,
  Indie Hackers, and Product Hunt. None posted.
- **`submission-tracker.md`** — every channel considered, with an
  honest status (see the final report below for the synthesized
  version).

## Bottom line

Read the final report delivered in the conversation for the ranked
first-10-actions list, the HIGH/MEDIUM/LOW channel classification, and
what's actually done vs. still needs a human. The short version: the
GitHub repo's own Topics/description are still blank (the single
highest-value, lowest-effort fix available and nobody has taken it),
two awesome-lists are genuinely strong fits with PR content ready to
paste, and eight real projects were found who are — right now — running
exactly the naive trimming code token-budget replaces.
